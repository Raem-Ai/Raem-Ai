# RAEM AI

AI agents, apps, and automations for real operational work.

RAEM AI, Inc. is a Miami company run by one person, Carlos Garcia, and a team of AI agents that research, build, and ship alongside him. A person approves anything that matters.

## What we're building

- **SARVVIS**: an AI front desk for property managers that handles calls, texts, and WhatsApp
- **RAEM Freight**: a back-office platform for trucking carriers, from rate confirmation to billing
- **FLOW Lite**: a simple budgeting app, live at [flow.raem.ai](https://flow.raem.ai)
- **Auron**: the internal team of AI agents that runs RAEM's marketing

## How we build

Everything is built with Claude Code using a supervisor-and-crew workflow: one model plans and judges the work, a crew of agents builds it, and nothing ships without a first-hand check.
